Sıkça Sorulan Sorular

Yazılıma ne zaman başladın?

Kodlamayla ilk tanışmam Scratch ile oldu, 5 yıl 9 aydır aktif kullanıyorum. Metin tabanlı kodlamaya ise 2026'da HTML ile başladım.

Projelerinde yapay zeka kullanıyor musun?

Evet, bazı projelerimde (örneğin Sayı Avı oyununda) yapay zeka desteği alıyorum. Bunu her projede açıkça belirtiyorum ve süreci inceleyip anlayarak ilerliyorum; amaç kopyala-yapıştır değil, öğrenmek.

Bu siteyi nasıl yaptın?

Site tamamen sıfırdan, herhangi bir hazır şablon veya JavaScript kütüphanesi kullanılmadan HTML, CSS ve saf JavaScript ile yazıldı. Kaynak kodu GitHub profilimde görülebilir.

Sırada hangi dil var?

Java. HTML ve JavaScript temelimi oturttuktan sonra nesne yönelimli programlamaya Java ile geçeceğim.

Benimle nasıl iletişime geçebilirim?

Ana sayfadaki İletişim bölümünden e-posta gönderebilir ya da GitHub üzerinden ulaşabilirsin.
